# Related work and the design problem

This comparison records the documented workflows I reviewed on 18 November 2026. It looks at how people locate a sound, listen back, organise an observation and pass it to someone else.

## The closest music-analysis comparisons

### [EAnalysis](https://logiciels.pierrecouprie.fr/?page_id=402)

Pierre Couprie’s analytical workspace supports graphical events over sonograms, custom analytical parameters with defined values, and separate views for structure and other representations. It can loop a passage and organise excerpts into a playlist. Its documented spectral-filter workflow takes a drawing or shape and computes a filtered track using [IRCAM’s SuperVP as documented in the filter guide](https://logiciels.pierrecouprie.fr/telechargement/EANALYSIS/EAnalysisHelp/pages/filters.html). Project-data exports can include chosen parameters from events, markers and charts in text, CSV, JSON or XML. The overlap is substantial, especially for teaching electroacoustic music. [Analytical events](https://logiciels.pierrecouprie.fr/telechargement/EANALYSIS/EAnalysisHelp/pages/addAnalyticEvents.html) · [Playback and playlists](https://logiciels.pierrecouprie.fr/telechargement/EANALYSIS/EAnalysisHelp/pages/playback.html) · [Project-data export](https://logiciels.pierrecouprie.fr/telechargement/EANALYSIS/EAnalysisHelp/pages/exportData.html)

For teaching, those facilities support building a detailed representation of a work and deciding how to model its musical parameters. HearPlot starts with a smaller task. A student can choose a musical category, draw a region, hear the selected band from the saved note, and attach a second example to the same observation. For mix feedback, the same note can be copied as part of a category-grouped message or sent in an editable session. The band is applied during playback of the recording.

### [Sonic Visualiser](https://sonicvisualiser.org/doc/reference/5.2.1/en/)

The Boxes layer saves labelled time–frequency rectangles over a spectrogram. The workspace also supports detailed spectrogram settings, zoom, plugin-based feature extraction, looping selected time extents, and exports of annotation layers. Its manual describes drawn boxes as persistent annotation objects and playback selections as time extents. A session can be shared with someone who has the audio. [Boxes](https://sonicvisualiser.org/doc/reference/5.2.1/en/#boxes) · [Selection](https://sonicvisualiser.org/doc/reference/5.2.1/en/#selection) · [Version 5.2 reference](https://sonicvisualiser.org/doc/reference/5.2.1/en/)

For teaching, editable layers are useful for putting a learner’s observations alongside measured onsets, notes or other analytical data. HearPlot gives the learner a note with a musical category and one or more regions they can play or loop, including playback of the saved frequency band. For mix feedback, the plain-text handoff is already organised by musical category and time, including the frequency limits and linked regions. A colleague can read it in a message or reopen the editable session with the recording.

## The problem HearPlot addresses

A listener can hear a detail in a dense recording, write about it, and still leave the next person guessing which sound they meant. A timestamp helps them find the passage. The rest of the reference can get lost in the handoff, including the frequency area to attend to, the musical element under discussion and the other passages that illustrate the point. The tools above address many parts of that problem. My design question is how to keep those details together in one workflow for analysing a recording and sharing observations about it.

An annotation in HearPlot stores a written observation, a musical category and one or more regions with start and end times. A spectrogram region also stores its frequency limits. Play and loop controls let a listener focus on those frequencies while keeping the selection tied to the original recording. **Copy text** groups notes by category and orders them by time within each category. The text includes time ranges, frequency limits where selected, and any linked regions. It can be pasted into an assignment, an analysis draft or an email. An editable JSON session preserves the regions for a recipient who opens the same recording.

For a student or independent listener, that means collecting audible examples for an interpretation, revisiting them and comparing what happens in different parts of a work. For an artist, mix engineer or label A&R team, it means handing over a readable set of observations about a mix or composition, with enough detail for the recipient to find and hear each issue. The question for evaluation is whether the workflow helps students make more specific observations and helps recipients find the sound a feedback note refers to.
